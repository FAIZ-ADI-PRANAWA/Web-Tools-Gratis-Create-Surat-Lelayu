## ✨ Description

**Cetak Lelayu** is a free, online web application designed to simplify the creation of traditional Javanese condolence letters and announcements (known as `Surat Lelayu` or `Pawartos Duka`). This intuitive tool allows users to quickly fill in relevant information about the deceased and the funeral arrangements, generating a neatly formatted A4 PDF document instantly. The generated PDF is ready to be printed or shared digitally via platforms like WhatsApp, significantly easing the burden on grieving families and community organizers.

Built entirely client-side, **Cetak Lelayu** ensures the privacy and security of sensitive data, as no information is stored or processed on any server. It's a micro-tool that bridges traditional customs with modern digital convenience.

## 🚀 Features

Cetak Lelayu offers a streamlined experience for generating condolence letters with several key features:

*   **📝 Customizable Header**: Easily set the organization/community name (e.g., IKATAN PEMUDA PEMUDI MANUNGGAL HATI) and address details for the letter's header.
*   **✉️ Recipient Details**: Input the intended recipient of the condolence letter (e.g., Bapak /Ibu /Saudara /Masyarakat).
*   **👤 Deceased Information**: Fill in the status (`Almarhum`/`Almarhumah`), full name, alias, and age of the deceased.
*   **🕒 Time & Place of Death (`Sedorikolo`)**: Specify the day, date, time, and location of passing.
*   **⚰️ Funeral Arrangements**: Provide details for the burial day, date, time, and cemetery name.
*   **👨‍👩‍👧‍👦 Family List**: Dynamically add and manage a list of family members enduring sorrow.
*   **✍️ Custom Footer Notes**: Include personalized messages or institutional details at the bottom of the document.
*   **🖼️ Optional Logo Uploads**: Enhance professionalism by uploading custom logos for both the left and right sides of the letterhead.
*   **⬇️ Instant PDF Generation**: Generate a professional A4-sized PDF document ready for download, printing, or sharing with a single click.
*   **🎨 Dark/Light Mode**: Toggle between light and dark themes for improved user experience.
*   **📱 Responsive Design**: The interface is optimized for various screen sizes, from mobile devices to desktops.
*   **🔒 Client-Side Processing**: All data input and PDF generation occurs directly in your browser, ensuring maximum privacy and security as no personal data is ever sent to a server.
